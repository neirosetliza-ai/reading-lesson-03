# Слог за слогом · Урок 03

Интерактивный урок чтения на русском языке. Продолжительность: 45–60 минут.

## Задания

1. Таблица из 20 слогов с согласными В, З, Р, Л.
2. Ползунок для плавного слияния согласного и гласного.
3. Цветок слогов: согласная в центре и гласные на лепестках.
4. Простые слова из двух слогов: вата, вода, горы, розы, коза, пила.
5. Расшифровка слов по символам с выбором картинки: слон, сок, лак, нос, сон, оса.

В уроке нет озвучки. Прогресс сохраняется в браузере на устройстве ученика. Данные не отправляются на сервер. Есть подсказки для взрослого и сброс прогресса.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей и сборка не требуются. Для размещения на статическом хостинге загрузите `index.html`, `style.css`, `app.js` и папку `pictures`.

## Состав проекта

- `index.html` — страница урока и инструкция для взрослого.
- `style.css` — адаптивное оформление.
- `app.js` — задания, проверка ответов и сохранение прогресса.
- `pictures/` — иллюстрации в формате SVG.

Шрифт Manrope загружается из Google Fonts; при отсутствии подключения используется системный шрифт.

## Учебная основа

Первые упражнения адаптированы по мотивам пособия В. Г. Дмитриевой «Тренажёр по чтению», печатные страницы 1–3. Задание с шифром адаптировано по предоставленному образцу. Книги, фотографии и аудиозаписи в репозиторий не включены.
